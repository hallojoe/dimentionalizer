# A CV in layers · 16 years

Open **Presets → Work & study → A CV in layers · 16 years**, then **Apply configuration**. The preset is also available through **Spaces → Add a space → A preset template**.

Alex Rowan, the employers, the businesses, and all responsibilities and outcomes are fictional. This is an editable example of a CV structure, not a real person's history.

## Employment timeline

The six consecutive employments cover **January 2010–December 2025**, exactly 16 complete calendar years. Each employment or contract has its own auto-fit plane, two responsibility groups, a role summary, and four function objects. Select a role to inspect its dates, engagement summary, and responsibilities; select a function for the work performed.

Height encodes **start year**, using `5 × (start year − 2010)`. Group and object elevation offsets are zero, so responsibilities sit at their employment's chronological level. Height does not encode importance, seniority, or duration. Horizontal positions use the existing automatic layout; numbered plane headings and five forward career-progression links establish the sequence.

## Exploring and adapting

- Select a plane in the directory to focus one employment and its functions.
- Use the employment/contract or private-business type filter to find role summaries.
- Use visibility switches to compare selected roles or temporarily hide side businesses. Frame controls can simplify the view while retaining function objects.
- Edit names, dates, function descriptions, and elevations in **Configure**; export JSON to keep a personal version. Dates are descriptive text, so update the start-year elevation when changing a period.

The preset contains **9 planes, 18 groups, 45 objects, and 47 connections**. Animated effects and the world grid start off for a calmer CV view. All frames and entities start visible. It uses two declarative custom types that reuse built-in Office and Shop geometry; no external model assets are required.
